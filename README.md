# ☕ Coffee Sales Dashboard (Power BI Project)

## 📌 Overview

This project showcases an interactive Coffee Sales Dashboard built using Power BI and Excel. It analyzes sales performance, customer behavior, and product trends.

---

## 🛠️ Tools Used

* Power BI
* Microsoft Excel
* DAX (Data Analysis Expressions)

---

## 📊 Dashboard Features

* KPI Cards (Total Sales, Orders, Top Country, Top Coffee)
* Sales Trend Over Time
* Sales by Coffee Type
* Sales by Country
* Top 5 Customers
* Interactive Filters (Date, Roast Type, Size, Loyalty)

---

## 🔍 Key Insights

* United States contributes the highest revenue
* Excelsa is the top-selling coffee
* Sales peak during mid-year months
* Few customers drive major revenue

---

## ⚙️ Data Processing

* Data cleaned using Excel (TRIM, CLEAN, XLOOKUP)
* Data modeled in Power BI using relationships
* Measures created using DAX
